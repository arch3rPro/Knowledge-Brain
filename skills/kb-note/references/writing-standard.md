# Ordinary note writing standard

Use this standard for ordinary Markdown in user-defined theme directories. It does not define managed Wiki schema or user directory names.

## Before writing

- Identify the knowledge object, the question or focus, and the intended reader.
- Inspect nearby notes and local conventions. Update an existing note when its scope already matches; otherwise create a distinct note.
- For changing software, services, protocols, or policies, record the relevant version or branch and the research date.
- Use available research tools when the task requires external facts. Do not imply that unavailable or unread sources were checked.

## Structure and evidence

- Lead with a concise summary that answers the note's central question.
- Organize sections around the subject, not the chronology of the Agent's work.
- Put claims near their supporting links. A bare source list does not show which claim a source supports.
- Clearly distinguish observed facts, source claims, inference, recommendation, and unresolved questions when confusing them would change a decision.
- Include concrete usage or examples only when they improve understanding; do not pad every note with the same sections.
- Record limitations, version sensitivity, conflicts between sources, and anything not independently verified.

## Naming and maintenance

- Use an object identifier plus focus in the filename and first heading, such as `matt-pocock-skills-overview.md`.
- Prefer one useful synthesis over several thin files. Split only when parts have distinct long-term purposes.
- Preserve useful user-authored text and links during updates. Do not silently replace opinions with Agent conclusions.
- Use ordinary Markdown links for related notes. Do not invent a fixed taxonomy, mandatory frontmatter, or a relationship schema.

## Completion check

Before reporting completion, verify that the path fits the subject, the title identifies the object, major claims have traceable sources where applicable, facts and inference are not misleadingly blended, and no ingestion or Wiki operation was triggered.
