# Knowledge-Brain v0.1.3

本版本补充 Vault 结构升级与外部同步检查，完善受管理 Wiki 的删除、移动和来源校验，并新增面向普通调研文档与主题笔记的 `kb-note` Skill。

## Vault 升级与同步

- 新增 `kb vault upgrade`。默认只生成完整差异预览，确认后仅更新 Knowledge-Brain 管理的模板文件和 `KB.md` 规则区块。
- 新 Vault 使用 `.kb/template.yml` 记录独立的模板版本；旧 Vault 可识别已知历史基线，未知修改保持冲突状态，不覆盖用户内容。
- 模板升级不会修改主题目录、普通笔记、准入清单、Wiki 正文、Git 或 Obsidian 设置，并支持陈旧预览检测和中断恢复。
- 新增只读的 `kb sync check`，检查 Git、Obsidian、设备本地配置和可重建状态是否适合外部同步。Vault 不要求使用 Git，也不会由该命令执行任何 Git 操作。
- Vault 路径继续由各设备本地解析，不写入可同步配置，支持同一 Vault 在不同设备使用不同绝对路径。

## Wiki 与来源安全

- `kb knowledge save` 支持显式删除和移动受管理的 research/article 页面，并同步维护索引、日志、旧哈希保护和中断恢复状态。
- 知识计划拒绝同一 Wiki 分区中的重复标题；`kb lint` 会报告已经存在的重复标题。
- 新建受管理内容使用 `kb.origin` 区分外部调研与用户原创。外部调研必须引用已保存的精确 `kb-source://` 版本，普通 URL 不能替代准入证据。
- 来源更新不会使已保存的旧版本失效。旧哈希继续表示当时使用的精确证据，lint 以警告提示它不是当前版本，不会自动替换引用。
- Vault 存在未完成的模板升级或来源/知识写入时，相关入口拒绝读取或写入可能混合的状态。

## Agent Skills 与普通笔记

- 内置 Skills 增至九项，新增 `kb-note`，用于普通调研文档、项目分析、概念笔记和使用笔记。
- `kb-note` 读取 Vault 规则、当前 CLI 能力和准入状态；新建重要调研内容时，可以只读查询已有 Wiki 和保存来源，并检查主题目录中的普通笔记。
- `kb-note` 提供独立写作标准、调研模板和常青笔记模板。模板不强制用户目录、frontmatter 或固定章节。
- 普通笔记写作不会自动保存来源、修改受管理 Wiki 或执行 operation。宿主桥接说明明确区分 `kb-note`、`kb-ingest` 和 `kb-save` 的授权范围。
- `admission.yml` 仍只准入 Vault 根目录下的一级目录；启用后根据 `include/exclude` 规则递归处理其内部子目录，不要求笔记平铺。

## 已知限制

- `kb-note`、新增宿主适配和自然语言触发效果将在发布后使用真实 Agent 验证；当前兼容声明不扩展到尚未验证的宿主行为。
- 来源版本变化可以通过 lint 发现，但当前没有自动生成受影响 Wiki 清单或批量更新内容的命令。
- `kb sync check` 只检查本地兼容状态，不执行拉取、推送、合并或冲突解决。
- macOS 二进制尚未 notarize，Windows 二进制尚未使用 Authenticode 签名。
