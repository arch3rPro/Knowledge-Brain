# Knowledge-Brain v0.1.0

Knowledge-Brain 的首个公开 CLI 版本，提供一套跨平台、文件优先的本地知识库工作流。知识正文保持为人和工具都能直接读写的 Markdown、YAML 与普通目录；CLI、Agent Skill、MCP 和 HTTP 接口共享同一应用层。

## 主要功能

- 初始化新 Vault，或先审核再采用已有目录；初始化不会自动创建 Git 仓库或个人分类目录。
- 使用 `admission.yml` 明确指定允许处理的一级主题目录。
- 检查并保存 Markdown、文本和常见办公文档来源，保留原始对象、来源记录和内容哈希。
- 默认直接查询真实 Markdown；可选 BM25F 索引支持字段加权、中文检索、跨目录搜索和完整重建。
- 使用固定的 `Wiki/external-sources/`、`Wiki/research/`、`Wiki/articles/` 三层结构组织长期知识。
- 创建带逐文件 SHA-256 清单的 ZIP 备份，并在恢复前验证内容。
- 提供八个可移植 Agent Skills、只读优先的 MCP stdio，以及可选的 HTTP/SSE 服务。
- 提供带 Minisign 验证的显式 `kb update check` 和 `kb update`；不会在普通命令启动时自动联网。

## 下载与安装

| 系统 | 二进制发布包 |
| --- | --- |
| Linux x86_64 | `knowledge-brain-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple Silicon | `knowledge-brain-v0.1.0-aarch64-apple-darwin.tar.gz` |
| Windows x86_64 | `knowledge-brain-v0.1.0-x86_64-pc-windows-msvc.zip` |

这些不是源码包。解压后，Linux 和 macOS 包内的可执行文件是 `kb`，Windows 包内是 `kb.exe`；每个包还包含 `LICENSE` 和 `INSTALL.md`。把可执行文件移动到 `PATH` 中的目录，然后运行：

```text
kb version
kb init ./my-knowledge
```

## 校验文件

- `SHA256SUMS`：三个二进制发布包的 SHA-256。
- `SHA256SUMS.minisig`：由项目更新密钥生成的 Minisign 签名。
- GitHub build provenance：每个平台构建任务生成的来源证明。

## 已知限制

- 目前只提供 Linux x86_64、macOS Apple Silicon 和 Windows x86_64。
- macOS 包尚未 notarize，Windows 程序尚未使用 Authenticode 签名，系统可能显示来源警告。
- PDF 提取、Embedding、rerank、WebUI 和桌面 GUI 属于后续扩展。
- v0.1.0 的更新发现使用 GitHub 匿名 API；共享网络出口耗尽匿名配额时，`kb update check` 可能收到 HTTP 403。请稍后重试，或安装包含无 API 版本发现机制的后续补丁版本。

完整设计、命令和 Vault 结构见项目 [README](https://github.com/arch3rPro/Knowledge-Brain#readme)。
