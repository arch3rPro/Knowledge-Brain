# Knowledge-Brain v0.1.1

这是更新检查可靠性补丁。它保留 v0.1.0 的 Vault、查询、BM25F、备份、Agent Skill、MCP 与 HTTP 能力，并修复共享网络中可能出现的 GitHub API 配额问题。

## 修复

- `kb update check` 不再调用每个出口 IP 每小时配额较低的 GitHub 匿名 API。
- 通过 GitHub 官方 `releases/latest` 跳转取得最新稳定版本，并只接受本仓库的精确稳定标签 URL。
- 下载地址固定到已解析版本；归档仍必须通过 Minisign 和 SHA-256 验证后才能安装。
- 非 GitHub 主机、其他仓库、格式错误版本和预发布标签都会被拒绝。

## 下载与安装

| 系统 | 二进制发布包 |
| --- | --- |
| Linux x86_64 | `knowledge-brain-v0.1.1-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple Silicon | `knowledge-brain-v0.1.1-aarch64-apple-darwin.tar.gz` |
| Windows x86_64 | `knowledge-brain-v0.1.1-x86_64-pc-windows-msvc.zip` |

归档内包含 `kb`（Windows 为 `kb.exe`）、`LICENSE` 和 `INSTALL.md`。解压后把可执行文件放入 `PATH`，运行 `kb version` 确认版本。

同时下载 `SHA256SUMS` 和 `SHA256SUMS.minisig` 可以验证发布包。macOS 包尚未 notarize，Windows 程序尚未使用 Authenticode 签名，系统可能显示来源警告。
