# Knowledge-Brain v0.1.2

本版本改进首次使用与 Agent 操作流程，扩展 Agent Skills 宿主，并加入基于 MCP 2026-07-28 的 Streamable HTTP。正式发布资产从本版本开始同时提供可直接下载的裸可执行文件和包含安装说明的完整归档。

## 使用体验

- README 快速开始区分 AI Agent 推荐入口和人类手动入口，并提供可直接复制给 Agent 的完整提示词。
- 新增连续的 AI Agent 操作指南，覆盖初始化、准入配置、来源保存、知识整理、查询、维护、备份和更新。
- `kb source save` 与 `kb knowledge save` 使用一次最终确认流程；高级 operation 命令保持可用。
- `kb maintain` 明确保持只读，只汇总实际状态、来源变化、Wiki lint 和诊断，不自动入库或整理知识。
- 人类可读输出使用短 Hash，JSON、MCP、HTTP 和持久化记录继续保留完整 SHA-256。
- `kb config admission add` 保留已有 YAML 列表风格和注释。

## Agent Skills

- 八个专项 `kb-*` Skills 支持完整目录资源，而不再假设每项只有 `SKILL.md`。
- `kb skills` 新增 OpenClaw、Hermes Agent、DeepSeek Harness 和 Pi。
- 新宿主使用各自原生 Skills 目录，不创建没有宿主语义的桥接文件。
- Hermes Agent 支持 User 范围；由于项目级发现依赖受信任 Git checkout，不把普通 Vault 伪装成 Hermes 项目安装。
- 支持 `hermes-agent`、`deepseek-harness` 和 `pi-coding-agent` 命令别名，受管理记录使用稳定短 ID。

## MCP

- `kb mcp` 默认 stdio 保持兼容现有 initialize-based `2025-06-18` 客户端。
- stdio 同时支持携带请求元数据、无需 initialize 的 MCP `2026-07-28`。
- 新增 `kb mcp --transport streamable-http`，默认在 `127.0.0.1:9433/mcp` 提供单一 POST endpoint。
- 支持 `server/discover`、可缓存的确定性工具列表、JSON 响应和请求级 SSE 工具结果。
- 默认只读；非回环监听或写入模式必须配置 Bearer token，浏览器 Origin 必须显式准入。
- stdio 与 Streamable HTTP 共用固定 Vault、工具实现、写入确认、陈旧状态检查和恢复机制。

## 已知限制

- OpenClaw、Hermes Agent、DeepSeek Harness 和 Pi 的目录适配已经实现，但各宿主中的自然语言触发仍需使用发布版逐一验证。
- MCP Streamable HTTP 已通过本地真实 CLI/TCP 测试；官方 MCP Inspector、第三方远程客户端和三平台运行验证将在本版本发布后使用发布二进制继续完成。
- macOS 二进制尚未 notarize，Windows 二进制尚未使用 Authenticode 签名，系统可能显示来源警告。
- 一步安装脚本、PDF/OCR、Embedding、rerank、原生 Agent Plugin、WebUI 和桌面 GUI 属于后续扩展。
