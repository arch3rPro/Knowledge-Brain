# Install Knowledge-Brain

1. Download the archive that exactly matches your operating system and CPU.
2. Verify `SHA256SUMS` and `SHA256SUMS.minisig` before extracting the archive.
3. Extract the archive and place `kb` (or `kb.exe` on Windows) on your `PATH`.
4. Run `kb version` to confirm the installed version.

Only binaries installed from an official GitHub Release support `kb update check`
and `kb update`. Builds installed with Cargo or compiled from source remain under
their package manager's control.
