# Wiki Lint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a read-only `kb lint` command that validates OKF v0.2, the explicit Knowledge-Brain Producer Profile, links, source-version references, freshness, and portable Wiki paths.

**Architecture:** `kb-core` owns reusable OKF document parsing and validation vocabulary. `kb-app` owns Vault traversal and cross-document/source checks and returns a typed report. `kb-cli` only maps arguments, rendering, and the optional strict exit policy.

**Tech Stack:** Rust 2024, `serde_yaml_ng`, `time`, `pulldown-cmark`, existing Vault safety and CLI envelope code.

**Spec:** `.superpowers/specs/2026-09-07-wiki-lint.md`

## Global Constraints

- Rust MSRV remains 1.85.
- The operation is deterministic, offline, and read-only.
- Paths and behavior remain portable across Windows, macOS, and Linux.
- Unknown OKF and `kb` fields remain accepted.
- `--strict` changes only the CLI exit code.
- Run only focused tests for this task; do not run the full workspace suite.
